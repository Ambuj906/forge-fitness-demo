# FORGE FITNESS — Website Demo

A premium, responsive fitness website concept built with HTML5, CSS3 and vanilla JavaScript.

**Project status:** Local demo built; initial browser QA reported complete. Deployment has not yet been verified.

## 1. Project overview

FORGE FITNESS is a fictional fitness brand created to demonstrate website design and development services for gyms, fitness studios and personal trainers.

The design uses:

- Dark charcoal and off-white sections
- Lime-green accents
- Bold editorial typography
- Fitness photography
- Responsive layouts and mobile navigation
- Clear membership and contact calls to action

All business details, people, membership prices, location and opening hours are illustrative demo content.

## 2. Project structure

```text
demo-fitness-studio/
├── index.html
├── styles.css
├── script.js
├── README.md
└── QA-CHECKLIST.md
```

## 3. Technology

- HTML5 for page structure
- CSS3 for design and responsive layouts
- Vanilla JavaScript for mobile navigation
- Google Fonts for typography
- Unsplash-hosted images for photography

No framework, database, backend or paid API is required.

## 4. Run locally

1. Open the project folder in VS Code.
2. Open `index.html` in a web browser.
3. Keep an internet connection available for external fonts and images.

A local static HTTP server can also be used if one is available.

## 5. Customize the demo

Before adapting this design for a real business, update:

- Brand name and visual identity
- Headline and page copy
- Gym programs and facilities
- Trainer names, photographs and verified qualifications
- Membership prices and inclusions
- Actual address and operating hours
- Contact email and authorized WhatsApp number
- Page title and meta description
- Image selection and cropping

Replace all fictional information with details approved by the client.

## 6. Important limitations

- The website is a static frontend demonstration.
- No backend, payment system, booking system or working contact form is implemented.
- The email link uses `hello@example.com`, a placeholder address.
- The WhatsApp link uses a placeholder number and must not be treated as a real business contact.
- External images and fonts require network access and may change or become unavailable.
- Image licensing and suitability must be checked before commercial use.
- No production deployment or independent accessibility audit has been completed.

## 7. Initial browser QA

The developer reported passing these checks during manual browser testing:

- Desktop navigation links
- Tablet layout and navigation visibility
- Mobile menu opening and closing
- Escape-key menu closing
- Closing the menu after selecting a link
- Mobile hero heading and buttons
- Membership links to the contact section
- Email and WhatsApp link behavior
- Horizontal overflow checks
- Browser console error check

These are user-reported results, not an independent automated test report. They should be repeated after substantial changes and after deployment.

## 8. Deployment

The project can be published using a free static-hosting service such as Cloudflare Pages.

Before deployment:

1. Review all fictional content and placeholders.
2. Check image loading and mobile layout.
3. Complete `QA-CHECKLIST.md`.
4. Publish the project.
5. Test the actual public URL.

## 9. Commercial use

This project is a portfolio demo, not a finished website for a real gym. A client-ready version requires verified business information, approved assets, working contact details and any features agreed upon with the client.
